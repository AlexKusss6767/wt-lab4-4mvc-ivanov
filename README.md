## Описание
Лабораторная работа WT-4. Разработка веб-приложения на ASP.NET Core MVC.
Предметная область: интернет-магазин товаров.
Реализованы: список товаров, детали, создание, редактирование.
Используется Bootstrap для оформления.
Данные хранятся в памяти.
